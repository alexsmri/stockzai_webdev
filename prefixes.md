# Python:

## Class Names (PascalCase):

**DB**: Database communication
**UT**: Utility helpers

## Function Names (snake_case):

**get**: Get something securely
**post**: Post something securely
**util**: Utility helpers
**fetch**: Fetch something securely (async)
**make**: Factory helpers (tokens, payloads, etc.)

## Variable Names (snake_case):

**pr**: Props / payload input
**st**: State

# REACT / TSX:

## Class / File Names (PascalCase):

**UTI_**: Utility component or helper
**COM_**: React Component
**DCOM_**: Dumb / purely presentational component
**PAG_**: React Page
**PRV_**: React Provider
**CTX_**: React Context
**STO_**: React Store
**ITF_**: TypeScript Interface
**TYP_**: TypeScript Type Alias
**VAI_**: Domain-specific Value Interface (API payload shapes)

## Function Names (camelCase):

**use**: React Hook
**get**: Get something securely
**post**: Post something securely
**util**: Utility helpers
**fetch**: Fetch something securely (async)
**set**: Set state
**handle**: Handle an event or workflow

## Variable Names (camelCase):

**pr**: Props
**st**: State
**ut**: Function utilities / derived helpers
**cv**: Class variables

# SCSS / Styling:

## Class Name Prefixes (kebab-case):

**area-**: Layout containers and grids
**look-**: Visual treatments (typography, surfaces, inputs)
**mod-**: Utility modifiers
**img-**: Image sizing helpers

# Assets:

## File Name Prefixes:

**ICON_**: Icon assets
**IMG_**: Image assets
**LOGO_**: Logo assets
