**Python:**

Class Names (PascalCase):

DB*: Database communication
UT*: Utility

Function Names (snake_case):

get*\*: Get something securely
post*_: Post something securely
util\__: Utility
fetch\_\*: Fetch something securely (async)

Variable Names (snake_case):

pr*\*: Props
st*\*: State

**JS / TS:**

Class Names (PascalCase):

UT*\*: Utility
CO*_: React Component
PA\__: React Page
PV*\*: React Provider
ST*_: React Store
PI\__: React Props Interface

Function Names (camelCase):

get*: Get something securely
post*: Post something securely
util*: Utility
fetch*: Fetch something securely (async)
set*: Set State
handle*: Handle Event

Variable Names (camelCase):

pr*: Props
st*: State
